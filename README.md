# 보배드림 딜러 영상 스튜디오

중고차 딜러가 보배드림 매물 URL과 차량 사진으로 9:16 숏폼 영상을 빠르게 준비하는 웹 프로토타입입니다.

## 주요 기능

- 보배드림 매물 URL 데모 불러오기
- 차량 사진 순서 변경 및 정보 수정
- 영상 템플릿, 브랜드 색상, 길이 선택
- 브라우저 기반 세로 영상 렌더링과 다운로드
- SNS 게시 문구 자동 생성

## 로컬 실행

```bash
cd dealer-directory-app
npm install
npm run dev
```

`main` 브랜치가 갱신되면 GitHub Pages로 자동 배포됩니다.
